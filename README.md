# 2026 Spain & Portugal family trip

Single-file Korean trip journal for the March 30–April 20, 2026 family trip.

## Preview
Open `index.html` in a browser. On GitHub Pages, publish from the repository root.

## Editing
The itinerary and reservation display are stored in the `days`, `foods`, and `reservations` arrays near the end of `index.html`. Costs remain marked for verification because the source notes available for this build did not provide a verifiable total. Personal booking references, contact details, and identity data are intentionally excluded.
